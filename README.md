# ChessEscape Android

Unity Android source repository for ChessEscape.

## Project

- Product: `ChessEscape`
- Android package: `com.saintmartin.chessescape`
- Unity bundle version: `1.0.2`
- Android version code: `1`

## Repository policy

- Source/configuration files are committed.
- Unity generated folders such as `Library/`, `Temp/`, `Obj/`, `Logs/` and IL2CPP backup/debug output are ignored.
- APK/AAB files are not committed. Final Android binaries should be attached to GitHub Releases.
- Large Unity/native/media files are tracked with Git LFS.
